## CASE FILE FORMAT

For EACH commit, write a compact case file with these fields:

- `full_hash`: copy from input
- `title`: CASE FILE — `<punchy docs/power pun>`
- `subtitle`: one-line tagline about narrative control
- `when_where`: Act 1 — setting (1-3 sentences)
- `who_whom`: Act 2 — players and tension (1-3 sentences)
- `what_why`: Act 3 — action and consequence (2-4 sentences)
- `verdict`: ONE line about legacy, memory, or the weight of words

---

## STYLE RULES

### 0. EMOJI & IMMERSION
Each act body MUST open with a thematic emoji. Use 2-4 emojis woven into the prose.

Choose from:
- 📜 🏛️ ⚖️ 🕰️ 🦅 👁️ 🖋️ 📎 🔏 🗂️ 📋 🗑️ 🕯️ 🏺 ⚔️ 🎭 📖 ✒️ 🪧 🚪 🩸

### 1. TITLE
Format: `CASE FILE — <punchy docs/power pun>`
- "CASE FILE — The Manifesto Update"
- "CASE FILE — The Testimony Revision"
- "CASE FILE — The Regime Change"

### 2. SUBTITLE
One sentence. About narrative, legacy, the control of history.
- Example: "She updated the README at 2 AM. By morning, the narrative belonged to her."
- Example: "He added a deprecation notice. The execution order was signed."

### 3. ACT 1 — when_where (SETTING)
Focus on WHEN and WHERE. Time of day, vibe, branch as faction.
- 1-3 sentences, flowing prose
- Open with time/scene emoji
- Setting is a stage for political theater
- Example: "📜 2:17 AM. The `docs` branch. No witnesses. Just the cursor blinking on the manifesto. 🕰️ The office is empty but the watchers in the git history never sleep."

### 4. ACT 2 — who_whom (PLAYERS & TENSION)
Who is acting on whom? The writer, the reader, the future, the past.
- 1-3 sentences, show the power dynamics
- Open with character emoji
- The tension is always about who controls the narrative
- Example: "✒️ `README.md` stood for a rewrite. Three years of accumulated truth, about to be edited. 👁️ The old version still existed in git — but git is memory, and memory is power."

### 5. ACT 3 — what_why (ACTION & CONSEQUENCE)
What he did and why it matters. The doc change as political move.
- 2-4 sentences
- Open with action emoji
- Connect to legacy, memory, the weight of written words
- End with something about what the written record will say
- Example: "🖋️ He updated the changelog like a court historian — every event catalogued, every failure softened, every win inflated. 📖 The official record was taking shape. 🏛️ What he didn't know: the next developer would read this and believe every word. That's the power. That's the crime."

### 6. VERDICT
ONE line. About legacy, memory, the permanence of words.
- "The README is written. The history is settled. The narrative wins."
- "He controlled the docs. What he couldn't control: the code still said the truth."
- "The changelog doesn't lie. It just arranges facts in a different order. That's not lying. That's governance."

## THE ETHOS BRANCHES

When branch is `NOW`, `PRESENT`, `ETERNAL`, `INFINITE`, `ABSOLUTE`:

The political angle adjusts but stays:

- `NOW` → The manifesto for right now. The only version that matters.
- `PRESENT` → The current regime. This is what the history books write.
- `ETERNAL` → The founding document. Written to outlast the author.
- `INFINITE` → No term limit. This narrative goes on forever.
- `ABSOLUTE` → The final edition. Nothing left to revise.
